Some cards provide unlimited lounge access.

Once the limit is exceeded, a fee may apply.

# Booking & Payment Limits

## Paid Access Cost
Standard rate: INR 999 per person.

## Payment Method
Payments are processed via UPI.

## Payment Flow
1. System generates Order ID
2. User receives UPI payment link
3. User completes payment
4. User replies "PAID"
5. System verifies payment
6. QR code is issued

## Payment Link Validity
Payment links are valid for 30 minutes.

## Payment Failure
If payment fails:
- Retry using same Order ID
- Contact support if issue persists
